# Student Management System

A beginner-friendly student record management project built with HTML, CSS and JavaScript.

## Features
- Add student records
- View all students
- Search by name, roll number, email or course
- Edit student details
- Delete student records
- Save records in browser local storage

## How to run
1. Download and extract the project folder.
2. Open `index.html` in a web browser.
3. Add a student using the form.

No installation or server is required.

## Git practice
Open a terminal inside this folder and run:

```bash
git init
git status
git add .
git commit -m "Create student management system"
```

## Important note
This beginner version stores data in the browser's local storage. Data is not shared between browsers or devices and is not stored on an online server.
